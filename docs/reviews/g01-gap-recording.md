### 1.3 판정 규칙

- **DONE_VERIFIED**: 구현 위치와 그 요구를 직접 확인하는 test node가 있고, 그 node가 위 실행에서 통과했다.
- **DONE_UNTESTED**: 구현은 확인했지만 해당 요구를 직접 확인하는 node가 없다.
- **PARTIAL / MISSING**: 행마다 재현 근거(코드 경로, 검색식, 산술 또는 편차를 고정한 기존 시험)와 제안 후속 단위(§5의 GF-xx)를 적었다.
- **EXTERNAL_GATE**: 실장비, 전원 차단, 원본 소스처럼 자동 검증 범위 밖인 항목이다.
- **DEFERRED**: 설계 단계표에서 v1.0 이후로 둔 항목이다.

위험 열의 의미:

- 열린 gap의 심각도를 [품질 체계](../quality-system.md)의 S0~S3로 적는다.
- DONE_VERIFIED에는 열린 gap이 없으므로 `—`로 둔다.
- EXTERNAL_GATE는 미검증 상태로 배포할 때의 영향 등급이다.

GF-xx는 C00 확정 전의 제안 ID다. 파일·시험 계층·위험은 §5에 모았다.

## 6. 미해결 사항과 검토 요청

1. **S1 판정 확인 요청(G1A-11).** 원본 bytes는 보존되고 Library API(`transition`, `finalize_session`)로는 확정할 수 있다. 다만 사용자 경로(CLI·UI)로는 확정·내보내기·전사가 불가능하다. 그래서 "복구 불가·핵심 기능 실패"로 보았다. 독립 검토에서 등급 이견이 있으면 반례와 함께 남겨 달라.
2. **설계와 제품 계약·구현 사이의 결정이 필요한 항목.**
   - G1A-22: 시작 실패 시 PAUSED. 기존 시험이 편차를 고정하고 있다.
   - G1A-26: lease 만료 대신 단일 coordinator 증명.
   - G1A-53: 전사·요약을 파일 대신 DB에 저장.
   - G1A-17: CANCEL_UNCONFIRMED를 REMOTE_UNKNOWN 명칭으로 표현.
   - G1A-46: 에코 완화 범위.
   - G1A-15: 편차를 고정한 기존 시험의 기대값 정정.
   이 항목들은 작업자 권한 밖이므로 C00 결정이 필요하다.
3. **G01-B 경계.** `app/`·`ui/` 파일을 녹음 경로 판정 근거로 인용했다. 교차 검토와 C00 통합 때 G01-B 보고서와 중복되거나 누락된 항목(특히 G1A-62, G1A-72의 UI 측과 G1A-15의 provider 오류 코드 표)을 조정해 달라.
4. **재현 방식의 한계.** 배정 지시에 따라 기존 시험만 실행했고 임시 probe 시험은 만들지 않았다. PARTIAL·MISSING의 재현은 코드 경로, 검색식, 산술(G1A-33, G1A-56), 편차를 고정한 기존 시험(G1A-15, G1A-22)에 근거한다. 검토자가 독립 반례 시험으로 재현할 것을 권한다.
5. **외부 게이트.** 실장비(W01~W04), 전원 차단(G1A-66), VoiceLocal 소스(G1A-76)는 자동 검증하지 않았고 이 문서로 닫히지 않는다.
6. **작업 트리 동시 변경.** 작성 중 다른 세션의 패키징·GPU smoke 관련 변경이 작업 트리에 생겼다(§1.1). 판정 근거인 `src/`와 실행한 시험 파일은 HEAD와 같았다. 이 문서 외 파일은 수정하지 않았다.
